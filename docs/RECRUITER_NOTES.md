# Recruiter Notes

This repository is a portfolio-facing business website. It is useful as a signal for frontend architecture, interactive visual implementation, and production-minded static site work.

## What a Non-Technical Recruiter Can See

- Clear service positioning for agency partnerships.
- Bilingual presentation in Portuguese and English.
- Professional contact path through LinkedIn.
- A polished brand site rather than a placeholder landing page.

## What a Technical Interviewer Can Inspect

- Vue 3 component organization.
- Three.js rendering isolated behind a reusable backdrop component.
- Scene registry pattern for section-specific 3D states.
- Centralized i18n and SEO metadata.
- Post-build localized HTML generation.
- ESLint and production build scripts.

## What Automated Screening May Detect

- JavaScript and Vue codebase.
- Vite build tooling.
- Three.js dependency.
- pnpm lockfile.
- Documented lint and build scripts.
- Documentation beyond the README.

## Honest Gaps

- No test suite is currently present.
- No performance budget or Lighthouse report is committed.
- No screenshots are committed yet.
